# HIPER-CAOS

Web en español sobre filosofía contemporánea, tecnología y cultura digital. Incluye artículos introductorios y un recomendador de lecturas sobre realismo especulativo, aceleracionismo y hauntología.

## Archivos

- `index.html`: estructura y contenido.
- `estilos.css`: diseño y adaptación a distintos tamaños de pantalla.
- `app.js`: recomendador de lecturas y resaltado de artículos.
- `imagenes/`: recursos gráficos.

## Uso

Abre `index.html` en un navegador. No requiere instalación ni dependencias.
